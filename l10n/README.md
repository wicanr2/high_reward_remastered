# 遊戲內譯文

繁中保留原版文字及已接受的 17 項校訂。簡中、日文、韓文、英文各有七檔 2559 項接受譯文，共 10236 項；接受摘要見 `ACCEPTANCE.json`。表內 `note` 保留候選階段紀錄，正式七檔採用以 `status` 及 `acc_sha` 為準。MAIN.EXE.tsv 補充顯示文字，未知項保留原文。

文字檔與顯示疊層共同接入遊戲；不修改原版檔案、識別值或存檔。F4 儲存下次啟動的遊戲語言偏好。英文使用雙字共格，韓文普通空白前進 8 像素。

`glyph-patch/` 只含 Noto 產生的五檔字模補丁與 OFL 聲明，沒有原版 CFONT。新增文字缺字或英文新字組須用 `tools/l10n/bakeglyphs.sh` 重烘。含原版資料的語言包在使用者資料目錄生成，不提交。

使用者授權在本 private repo 收錄表內原文、譯文及字模補丁。未經母語者審閱；不宣稱全遊戲版面或原版 parity 驗證。
