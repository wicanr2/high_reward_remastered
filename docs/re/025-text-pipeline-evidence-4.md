## 3 任務 2：預測（先於實測）

### 3.1 手算模型

依 `docs/re/023` 第 2.2 節與 `workplace/ida-text/out/d2.txt` 第 338 至 420 行（`25DC:1676` 反組譯，位元組已讀）：

- 迴圈頂端條件：`*p != 0`、`*p != 0x0A`、`8*si < 最大寬`，三者皆真才進本體。
- 本體：`966C(*p, 0)`（AH 在此處為 0：`1689` 前一道是 `mov ax,1` 或 `xor ax,ax`，零擴充）。S 集（回 0）→ 畫 `*p`、`p++`、`si++`、回頂端。P 集（回 1 或 -1）→ 畫 `*p`、`p++`、`si++`；若 `8*si > 最大寬` 或 `*p == 0` 離開；否則**不查 `0x0A`**，`16EC` 無條件畫下一個位元組、`p++`、`si++`，回頂端。
- 離開時 `*p == 0x0A` 則 `si++`（換行由此被吃掉），回傳 `si`；`18AC` 以回傳值推進下一行。所以「兩行」＝ `1676` 呼叫 2 次（y 差 16），「併行」＝ 呼叫 1 次。
- 畫字函式 `198C:02E1`（IDA `287C:02E1`）：參數 `arg_0`＝位元組、`arg_2`＝x、`arg_4`＝y（`push` 順序見 `d1.txt` 第 284 至 345 行）。它自己配對：旗標 `4D3CE` 為 0 且位元組 `>= 0x80` → 存為 lead 不畫；旗標為 1 → 當 trail 畫雙位元組字；旗標為 0 且位元組 `< 0x80` → 半形字。所以 `0x0A` 被 `1676` 畫出時，若沒有待配對 lead，畫成半形字（索引超出表，雜訊字模）。
- S 集 ＝ `20` 至 `7E`、`A1` 至 `DF`；P 集 ＝ `01` 至 `1F`、`7F` 至 `A0`、`E0` 至 `FF`。
