# 004 中斷使用普查（常駐映像）

日期：2026-10-03
範圍：`MAIN.EXE`（常駐映像；overlay 內的 `int` 指令為 0，見 `docs/re/007` 第 9 節）、`OP.EXE`、`END.EXE`、`SIG.COM` 的 `int n` 呼叫，以及呼叫前可解出的 `AH` 或 `AX` 常數。
方法：`tools/ida.sh run <檔名> ida_int_census.py /work/out/<輸出>.json`，往前最多 8 道指令找 `mov ax/ah, imm` 或 `xor ah, ah`；解不出的另列。原始輸出：`data/004-int-census-main-op-end.txt`。
推論等級：confirmed（反組譯與位元組可重跑）、強推論、假說、未知。

## 1. 結果（confirmed）

三支主程式共用同一組執行期，呼叫集合幾乎相同。`MAIN.EXE` 常駐映像共 61 種（中斷號、AX 或 AH）組合：

| 中斷 | 用到的功能 | 備註 |
|---|---|---|
| `10h` | `AH=01`（游標形狀）、`AX=0003`（文字模式 3）、`AX=1000`、`1001`、`1010`（調色盤與 DAC 暫存器）、`AX=1800` | `int` 指令層面沒有 `AH=00` 的呼叫；視訊模式由 `_int86(0x10)` 設定（見第 4 節） |
| `21h` | 檔案：`3C`、`3D`、`3E`、`3F`、`40`、`41`、`42`、`43`、`44`；記憶體：`48`、`49`、`4A`；`67`（設定控制代碼數）；`4C`；`AX=5801`；`30`；`2A`、`2B`、`2C`、`2D`（日期時間）；`25`、`35`（向量，含 INT 0、4、5、6、`1C`）；鍵盤：`08`、`0B`、`AX=0700` | `AX=4C03` 為結束碼 3 |
| `23h` | `AX=0000`，一處 | 呼叫 Ctrl-C 處理常式 |
| `67h` | `AX=4000`、`4100`、`4300`、`4400` 至 `4403`、`4500` | EMS：狀態、取頁框位址、配置頁、映射、釋放。各一處 |
| `81h` | `AX=0000`、`0001`、`0002` | 見第 2 節 |

沒有 `int` 指令的中斷：`16h`（BIOS 鍵盤）、`33h`（滑鼠）、`15h`、`2Fh`、`31h`。滑鼠與視訊模式經 C 函式庫的 `_int86` 呼叫（`int` 指令普查看不到，見第 4 節）。XMS 沒有透過 `2Fh` 偵測的跡象。

`OP.EXE`（53 種）、`END.EXE`（56 種）的集合與 `MAIN.EXE` 大致相同。差異：`OP.EXE` 與 `END.EXE` 沒有 `21h` 的 `AH=2A`、`2B`、`2C`、`2D`；`END.EXE` 多一處 `AX=6300`（DOS 的 DBCS 領先位元組表）。逐項見原始輸出。

## 2. `SIG.COM` 與 `int 81h`（confirmed）

- `SIG.COM` 內有 `AX=3581`（取向量）三處、`AX=2581`（設向量）兩處、`AX=3100`（結束並常駐）一處。它是安裝在 `int 81h` 的常駐程式。
- `MAIN.EXE`、`OP.EXE`、`END.EXE` 各自呼叫 `int 81h` 的 `AX=0000`、`0001`、`0002`。
- `HR.BAT` 在 `OP` 之前載入 `sig`，結束時 `sig /r` 移除。jsdos 版只跑 `main`，不載入 `sig`。

強推論：三支程式透過 `int 81h` 與 `SIG.COM` 溝通，呼叫的功能編號 0、1、2 的意義未知。`SIG.COM` 字串稱它為「Signal Socket」。

## 3. 對 M3 的意義

- 啟動順序有兩條：jsdos 的 `main`，以及 `HR.BAT` 的 `sig`、`OP`、`MAIN`、`END`。dosgolem 的 `-queue` 參數可以在主程式常駐後接著跑下一支（`docs/spec/009-exec`），可以測 `sig` 先行。兩條路徑的行為差異要以收據比對。
- 圖形模式：由 `_int86(0x10)` 以 `AX=0012h` 設定（VGA 模式 12h，640x480，16 色），見 `docs/re/007` 第 9 節與 `docs/re/006` 第 2 節；`PSH.EXE` 的 PCX 顯示模式未知。
- EMS 是必須的（全套 `int 67h`）。XMS 與 BIOS 鍵盤沒有用到；滑鼠經 `_int86(0x33)` 使用；鍵盤走 DOS 的 `AH=08`、`0B`。

## 4. 限制

這份普查只涵蓋 `int` 指令。經 `_int86` 的軟體中斷（`_int86(0x10)` 設視訊模式、`_int86(0x33)` 滑鼠共 14 處）要看 `docs/re/007` 第 9 節。呼叫前以 `mov ah/ax` 解出常數的方法會漏掉以暫存器傳入或較遠處設定的情形，結果是下限，不是完整清單。原始輸出 `data/004-int-census-main-op-end.txt` 的位址格式是「線性位址 / 16 : 餘數」，不是 IDA 選擇子（例：`29C9:0006` 即 IDA `29C4:0056`）。
