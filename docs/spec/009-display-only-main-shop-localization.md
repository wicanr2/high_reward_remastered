## 2 顯示契約

- 不修改 MAIN、商店欄位、存檔、DOS 記憶體、暫存器或文字函式回傳值。
- 硬編碼文字、存檔名稱及格式展開後的文字，在 `16EC:15E7`、`16EC:1676` 或 `16EC:18AC` 被原版繪製時觀察。
- `15E7` 為單行，`1676` 的最大寬是像素；`18AC` 物件 `+4/+6/+8/+0A` 為 x、y、像素寬、像素高。原版常用 256×67、512×131；31×4 是位元組／行數換算，不能直接作像素尺寸。
- 對原始 Big5 字串做精確匹配。printf 格式先匹配展開後的捕獲值；譯文必須保持相同的格式符號順序，不執行譯文作為格式程式。
- 畫前與返回後各保存矩形像素。快照只保留仍與返回後像素相符的記錄；相同重畫不產生空差異記錄。
- MAIN 和 SHOP 只形成 `Frame.Display`。前端取得實際底圖所用的同一 Frame，在原版／HD／AI 畫面之後合成譯文。
- 對來源繪字造成的像素差異還原背景，隨後畫 Noto 字型。韓文及普通拉丁空白前進 8 像素，漢字及韓文字格前進 16 像素。
- 單行長名稱縮到原欄寬，保留所有字元。多行同時約束寬高，必要時縮小兩軸；單行欄中的換行合為空白。不藉裁切丟棄譯文。
- F12 保存已合成畫面，包含顯示層譯文。

## 3 失敗與權利

原版版本由執行層既有 MAIN／必要檔身分檢查綁定。顯示表列唯一、欄數、UTF-8、來源摘要及範圍須有效；SHOP 採用摘要必須符合目標文字。表或字型不能載入時記錄原因，MAIN／SHOP 退回原版顯示。不存在的翻譯、未知列、未採用列仍使用原版。

譯文與純 OFL 字型依本次使用者授權加入 private repo。原始 MAIN、SHOP、存檔、完整原字型及編譯語言包不加入 Git。來源名稱仍維持原版識別，格式匹配只用於顯示。

## 4 最低接線確認及限制

只要求編譯、四語來源載入及前端語言切換／README 畫面；不增加平台實機、戰鬥、存檔或原版對拍抽樣。未知 MAIN 列、圖像內文字及未執行的片頭片尾保留原版。長文字縮放可能降低字形清晰度，後續由使用者回報 GitHub Issue。
