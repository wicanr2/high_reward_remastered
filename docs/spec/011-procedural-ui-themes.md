## 擬定呈現契約

1. 執行層選項預設關閉，前端有 HD theme 時才開啟。只觀察原版呼叫與寫入，不改 Frame.Px、DOS 記憶體、VRAM、回傳值、時鐘、輸入或存檔。
2. `1D84:000A` 進入時核對參數及 128-byte PAT 摘要，返回 CS:IP、SS:SP 配對後才發布。只主題化 confirmed 不透明形狀，外側透明欄與列保持原背景。
3. metadata 由機器執行緒持有，每個像素記錄板面歸屬及字形保護。Frame 攜帶不可變副本，並以同幀呈現像素核對板面原色 Expected。
4. 旗標 0、畫面內的 `1C35:01C5` 使用原始 48-byte 遮罩保護字形與陰影，包含同值寫入。未知旗標及越界字形取消受影響區域的主題呈現，不以色彩猜字。
5. 未識別視訊寫入保守取消受影響 byte 欄的板面歸屬，後畫物件優先。新板面返回後，只在不透明形狀重設歸屬。板面與備份 metadata 有明確容量上限，缺項即原版回退。
6. `1F69:000E` 完成保存後，同時保存標頭對應的 metadata；身分包含 buffer 指標、標頭及原色資料摘要。`1F69:0169` 完成還原且身分相符後恢復；缺項、失配或越界保持原版。保存區尺寸不以板面尺寸代替。
7. 原版游標的已知保存／還原與貼圖保留下方板面歸屬。沿 010 先移除軟體游標，再驗板面；原版回退時保護仍可見的游標。最後畫獨立游標。
8. 前端只使用已上傳底圖配對的 Frame。F2 沿既有素材交易，缺 AI 圖、雜湊不符或錯誤時保留原版板面，按原因只記一次。
9. 板面與譯文擦除共用同一份背景取色。原字 Before 對到該 Frame 的板面 Expected 與歸屬時，才使用主題背景；其餘沿 009 回退。Noto、譯文及幾何不變，字型失敗保留原文。
10. F12 保存介面、譯文與游標的最後合成畫面。原版 bytes、PAT、字形與研究輸出不入 Git 或 Release；新生成 AI 板面沿現行公開授權。

## metadata 表示與提交點

這是顯示設計，不把新 metadata 當成原版資料格式。

- 固定 640×480 的歸屬畫布，每像素保存板面識別與字形保護位元。板面 Expected 在 far return 取得，之後不改。最多保留 64 個板面；失效識別不再主題化。
- `Machine.ObserveVideoWrites` 只觀察。已支持板面、已支持字形、已匹配 metadata 的背景還原及已知游標呼叫期間暫不取消歸屬，在返回時一次提交。其餘 A000 byte write 取消該 byte 對應八個像素的歸屬，包含同值寫入。這是保守回退，硬體 bit mask 不當成 PAT opacity。
- 字形來源遮罩的 1 bit 標為受保護，保留下方板面識別供譯文 Before 取色。未知字形仍走一般寫入回退。新板面只在其不透明形狀重設字形位元，透明邊界不影響舊畫面。
- 最多保留 64 份保存區、合計 1048576 個 metadata 像素，超額淘汰最舊項。摘要為 `SHA-256(header 的 8 bytes || header 指定的逐列四平面 bytes)`。只在 far return 完成後登記或恢復；指標重用而摘要不同時不得恢復舊 metadata。板面識別單調遞增，不把淘汰識別配給新板面。
- 游標例外只接受 010 的 DS `3E50:001D` 保存區與 `hd.CursorSite` 返回呼叫點、已知精靈格式。處理有效獨立游標時使用清除游標的呈現像素驗板面。原版回退仍排除游標實際不透明遮罩，無可驗證遮罩時取消相交板面的主題呈現。
- snapshot 將仍有歸屬的板面、字形保護及 Expected 複製到 Frame，原始資料由機器執行緒保存；合成執行緒只讀副本。未知模式、非 80-byte stride 或越界輸入不主題化。
- 背景取色使用同一個原版像素格的函式，HD／AI 板面和譯文擦除共用，輸出等比放大。只有 Before 與該像素歸屬的板面 Expected 相同時採主題色；字形保護位元不阻止這項受控擦除。無匹配來源時保持 009 的原版擦除。

## 失效、合成與同值字形

- 每個未完成呼叫記錄返回位置、SS:SP、進入步數及已觸及 byte 欄。snapshot 不主題化尚未完成呼叫觸及的像素。豁免只適用於已核對入口的當前原語寫入來源；未知巢狀寫入仍取消歸屬，並使相交的新板面提交失效。
- 已核對的游標貼圖／還原若尚未返回，但 010 已驗證同一 Frame 的完整游標或隱藏狀態，保留下方板面 metadata。未知、失敗或 CursorPending 的游標原語仍原色回退，不單凭原語種類跳過驗證。
- 未完成項最多 16 個，超過 2000000 步、返回堆疊不符、異常退出或超額時取消觸及區域及該項 metadata。保留原色畫面，不等未返回的原語，也不使它事後恢復失效 metadata。
- `Machine.ObserveModeChanges` 在任何模式設定時清除板面歸屬、未完成項與保存 metadata，因為平面清除不經 VideoWrite。這條觀察不讀 Palette，也不改模式或原始狀態。
- 總順序為 010 呈現底圖、既有 HD Composer、程序板面、板面內仍受保護的原字形像素、既有 Noto 譯文、F1／通知、獨立游標。原字形取同一呈現 Frame 的索引色與調色盤，避免 HD 戳記因同色而覆掉後畫文字。
- 板面像素保存最近有效繪製／還原步數，既有 HD 戳記另附原語完成步數 `DrawStep`，兩者同採 Machine.Steps，不比較不同來源的局部 Seq。新板面或 metadata 還原遮蔽較早 HD 戳記，即使原色相同。未知後畫寫入取消歸屬並標為原色回退；同幀、經 004 像素驗證且 DrawStep 晚於該寫入的精靈可保留既有 HD，避免把新畫肖像退回原版。其他取消區使用原色。受保護 glyph 仍取同幀原色，原版游標遮罩在所有步驟都優先保留。
- `DisplayStamp` 附上該次已匹配文字呼叫中的字形寫入遮罩，從已支持的原字形來源累加，包含 Before 等於 Expected 的寫入。有效譯文在字型已載入時同時擦除 changed mask 與這份 write mask；只有 owner 與 Before 匹配才取主題背景。未知 mask 的相交區域維持原版背景，字型失敗完全不擦原字。
- HD 發布與 GPU 上傳同時攜帶 RGBA、Frame、UI 樣式／素材身分。F2 已更新目標但 GPU 仍保留舊畫面時，板面和譯文背景都使用舊畫面的身分；不單讀 `sw.Current()`。原版底圖的 UI 身分為原版。這與 010 的 origFrame／hdFrame 配對共同生效。
- 未知寫入同時清除字形保護，回退步數逐像素取最新值。原字形恢復只處理目前仍有有效板面歸屬的字形位元；不把過期字形覆到新肖像上。原版淡入淡出時，材質依同幀白色索引 15 的 RGB 比例調暗；這是呈現近似，不新增原版硬體 parity 聲明。
