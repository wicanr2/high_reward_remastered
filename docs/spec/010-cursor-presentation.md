# 010：獨立滑鼠呈現

狀態：CONFORMED。2026-10-08。依據 [033](../re/033-cursor-presentation.md)，修正 Linux AppImage 游標閃爍與移動跳格。範圍包含原版、HD、AI theme；沒有 HD 掛鉤時亦可工作。完成範圍限於下列收據，不含使用者桌面的實機延遲測量。

## 契約

1. 執行層增加預設關閉的呈現選項；只有前端啟用。原版雜湊核對沿用 Open 的完整 MAIN.EXE 驗證。原版座標、指令、記憶體、VRAM、時鐘、输入事件及存檔保持不變。
2. `Frame.Px` 仍是原始 VRAM 快照，診斷與 oracle 保持原義。另附不可變游標資訊、清除游標的呈現像素與「重畫中」狀態，皆由機器擁有執行緒製作。
3. 只接受 40×32、五平面、805 bytes 的原版游標。DS `3E50:02A9` 供前端繪圖，`1BD1` 供當輪遮罩；背景使用 DS `001D` 的 648 bytes。全部尺寸、座標、界限先核對。透明值 16。
4. 旗標 0019/001B 有任一非零時，不把不完整游標當作可直接發布的底圖。已知有效格式的完整游標須背景標頭為 5×32、裁切精靈全部可見不透明像素與 VRAM 相同且至少一個不透明像素。背景位置只取保存標頭，不用最新輸入座標推算。背景還原僅寫呈現副本的游標不透明像素，裁切在 640×400 遊戲區。已知格式但 VRAM 比對失敗標示重畫中，前端最多保留上一張完整底圖 500 毫秒。持續失敗超過期限時回退原版底圖並關閉前端游標；下次有效快照可恢復獨立呈現。開機尚無有效精靈或精靈尺寸／格式不支援時顯示原始畫面，不猜測游標形狀，不進入無限等待。
5. 两旗標皆零時發布原始底圖，前端不繪製游標。HD 合成在有效獨立游標模式及隱藏分支都忽略 `hd.CursorSite` 戳記，使用同一份呈現底圖；重畫中不發布新合成畫面。回退原版分支維持原始戳記與像素，不疊加前端游標。
6. 前端使用已上傳底圖的游標資訊與調色盤。每次 Draw 以目前視窗滑鼠座標定位，遊戲座標換算與输入一致，無 8 像素對齊。限制範圍取該快照的 DOS Mouse Min/Max；Max=0 沿用驅動未限制的語意，VGA Y 轉遊戲 Y 減 40。熱點相減後位置下限為 0，畫面邊緣由裁切處理。視窗外不画游標。
7. 保留原版圖形，於遊戲與文字、說明疊層後繪製，所有 theme 共用。形狀或調色盤改變才上傳游標 GPU 圖；移動只改座標。F12 實際畫面截圖包含游標。系統游標維持隱藏，不產生雙游標。
8. 未知尺寸或精靈格式回退原版呈現；記錄原因一次。停機時不無限等待有效畫面；診斷仍可讀原始 Frame。

## 驗收與限制

- 執行層測試：精確還原背景；透明區保持原像素；輸入副本及記憶體不變；中間階段、隱藏、邊界與異常格式；關閉選項仍原始快照。
- 前端測試：同一底圖下新鼠標座標立即生效、所有 X 餘數、選單界限、熱點、視窗外、HD 去除游標戳記；競態檢查。
- 正常 Linux GUI：標題點新遊戲、進入遊戲、移動與左右鍵，F2 三種 theme、F1、F12。錄製前後畫面，檢查游標不消失、不留舊位置影像。不得由 direct-entry 或修改狀態取代。
- 發行重新建置 Linux AppImage；其他平台編譯並保留 macOS 實機未驗的限制。沒有承諾 DOS 输入或整個遊戲加速。
- 原版精靈與背景只存在玩家的原版資料及本機研究輸出，不加入版控。規格只保存定位與契約。
